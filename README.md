# 🎡 Interactive 3D Box Rotation

Ein cooles, kleines Webprojekt, bei dem du animierte 3D-Boxen drehen kannst – per Maus oder mit den Pfeiltasten auf deiner Tastatur.

## Screenshot
![noverMagicGame.png]( https://github.com/MsCodingLabs/numberQuessingGame/blob/main/numberGuessingGame.png)

## ✨ Was kann das Projekt?

- Die Boxen drehen sich in 3D, wenn du mit der Maus darüberfährst oder die Tastatur benutzt
- Farbige Hintergründe und coole Formen dank moderner CSS-Techniken
- Sanfte Animationen bei Bewegung oder Klick
- Der Code ist übersichtlich und kann leicht angepasst werden

## 🔧 Verwendete Technologien

- **HTML** – Struktur der Seite  
- **CSS** – für Farben, Formen, Animationen (`@property`, `clip-path`, `conic-gradient`)  
- **JavaScript** – steuert die Bewegung der Boxen

## ▶️ So startest du

1. Lade die Dateien herunter oder klone das Repository.
2. Öffne die Datei `index.html` in deinem Browser.
3. Bewege die Maus über die Boxen oder nutze die Pfeiltasten – und sieh, was passiert!

---

> Dieses Projekt eignet sich super, um mit CSS 3D-Effekten zu experimentieren oder eigene Ideen mit Animationen umzusetzen.
